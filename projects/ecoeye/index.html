01 / THE PROBLEM

Why this project exists

Reviewing CCTV footage manually makes it difficult to surface litter-related events consistently.

02 / TECHNICAL APPROACH

How the pieces connect

Video frames flow through object detection, with relevant events recorded through backend APIs and surfaced as alerts.

03 / ENGINEERING CONTRIBUTIONS

Implementation focus

  • Processed live video with YOLOv8 and OpenCV across more than five object classes.
  • Developed backend APIs for event logging and analytics.
  • Integrated incident alerts into a centralized dashboard.
