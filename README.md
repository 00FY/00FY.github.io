# Arnav Kale — Engineering Portfolio

AI automation, agentic systems, enterprise integrations and backend engineering.

The repository root contains the production static export served by GitHub Pages. `.nojekyll` preserves Next.js assets under `_next`. All eight project case studies and the downloadable portfolio PDF are included.

## Deployment

GitHub Pages publishes the `main` branch root. This repository contains only the generated public website and its downloadable portfolio PDF. The development source is maintained separately.

Conceptual illustrations are not product screenshots.
